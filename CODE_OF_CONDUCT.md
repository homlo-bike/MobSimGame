# Code of conduct

This project adopts the **Contributor Covenant, version 2.1**, available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and inclusive, welcome different viewpoints, accept
constructive criticism, focus on what is best for the community, and do not
harass anyone. Debates about mobility policy are welcome; personal attacks are not.

## Enforcement

Report unacceptable behaviour privately to the maintainers via GitHub (a private
security advisory or a direct message to the repository owner). Reports are
handled confidentially. Maintainers may remove, edit or reject contributions and
temporarily or permanently ban contributors who violate this code, following the
Covenant's enforcement guidelines.
