# MobSimGame

MobSimGame is an open-source, browser-based urban mobility scenario tool.

The project aims to help users compare mobility options such as:

- Walking
- Cycling
- Bus
- Bus rapid transit
- Tram
- Light rail
- Metro
- Private cars

The application will estimate and visualize:

- Potential ridership
- Changes in modal share
- Travel-time improvements
- Reduction in car dependency
- Construction costs
- Operating costs
- Energy consumption
- Emissions avoided
- Accessibility improvements

## Project status

Early prototype.

## Important principle

Estimated and assumed values must always be clearly distinguished from measured or imported data.
